# Remake character source

The user supplied their DEADSELL repository as the explicit remake reference: https://github.com/rockyhong-a11y/deadsell (retrieved 2026-10-04). The joint hierarchy, inverse kinematics, foot planting, toon materials, ponytail/scarf simulation, locomotion pose sequences, and female enemy/boss atlases are adapted from that author-owned work.

VEILBOUND adaptations include actual gun, paired gauntlets, barbed harpoon, cathedral greatsword and crescent scythe geometry; matching weapon-specific combat poses and phase metadata; a Blender 5.2-compatible per-frame renderer; native pixel hard-alpha atlas processing; and recorded motion measurements. Existing VEILBOUND weapon, skill and world assets are preserved.

The queen was regenerated from the authored rig using Blender 5.2 with larger transparent cells to recover 20 formerly clipped flail/effect frames. A dedicated 40 × 46 native HUD portrait is newly rendered from the same heroine rig.
